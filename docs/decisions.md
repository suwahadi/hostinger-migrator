Penggantian password sumber adalah operasi destruktif: lewat gerbang konfirmasi hapus email (sekali per batch) dan tercatat di `audit_log`. | Jawaban operator. Jalur ini tidak butuh password lama dari operator. Ketersediaan `/api/mail/v1` untuk Free Business Email wajib dibuktikan di akun uji (U8). |
| D-011 | 2026-11-22 | Cutover: lepas domain di sumber = checkpoint `MANUAL_SOURCE_RENAME`. Kuota website tujuan = tabel kuota paket standar Hostinger + konfirmasi operator. | Jawaban operator. Tidak ada endpoint ganti domain dan kuota untuk Shared Hosting. |
| D-012 | 2026-11-22 | Tambah dependency `golang.org/x/term` (modul resmi Go) untuk input token tersembunyi. Bila terminal tidak mendukung (mintty Git Bash lama), tool menampilkan peringatan dan menyarankan `winpty ./migrator.exe`. | PRD meminta token tidak di-echo; `bufio` saja tidak bisa menyembunyikan input. |
| D-013 | 2026-11-22 | Go 1.26 (stabil terbaru saat implementasi) lewat `go.mod`, toolchain diunduh otomatis. | PRD 5.1: Go versi stabil terbaru. |
| D-014 | 2026-11-22 | API client: GET diulang untuk gangguan jaringan (maks `retry_maks`) dan 5xx (maks 3 kali). POST/PATCH/PUT/DELETE **tidak** diulang otomatis kecuali 429 dan gagal koneksi (dial/DNS), karena request belum diproses. Selain itu dikembalikan sebagai `ErrUncertain` agar pemanggil memeriksa dulu apakah resource sudah terbentuk. | PRD bagian 10: operasi create yang timeout tidak boleh dibuat ganda. |
| D-015 | 2026-11-22 | API nyata mengirim header IETF `RateLimit-Policy: "api";q=90;w=60` (90 request per 60 detik). Default `rate_per_menit: 60` di config tetap dipakai (konservatif). Limiter juga membaca header `RateLimit` (`r=` sisa, `t=` detik reset) dan `X-RateLimit-*`. | Diverifikasi dari respons nyata `developers.hostinger.com` dengan token palsu pada 22 November 2026. |
| D-016 | 2026-11-22 | Pesan error API menyertakan `correlation_id` dari Hostinger (bila ada) untuk keperluan tiket support. | Format error nyata: `{"message":"Unauthenticated.","correlation_id":"…"}`. |
| D-017 | 2026-11-22 | Semua pemanggilan API wajib melalui contract registry (`internal/hostinger/contracts/*.yaml` di-embed ke binary). ID yang tidak terdaftar, berstatus `deprecated`, atau ber-path `agency-hosting` ditolak sebelum request dikirim. | PRD aturan agent poin 2 (jangan mengarang endpoint). |
| D-018 | 2026-11-22 | `migrator.exe` hasil build tiap fase di-commit ke `dist/migrator.exe` beserta `dist/SHA256SUMS`, lalu di-push ke `main`. Versi lama tertimpa oleh versi baru. | Keputusan operator. Konsekuensi: setiap versi menambah sekitar 14 MB ke riwayat git. |
| D-019 | 2026-11-22 | "known_hosts per akun" disimpan sebagai fingerprint SHA-256 host key di kolom `hosting_accounts.ssh_fingerprint` (TOFU), bukan file `known_hosts`. Fingerprint berbeda → status `BLOCKED`, hanya bisa dibuka dengan `migrator ssh setup <akun> --terima-host-baru`. | Satu sumber kebenaran di SQLite, ikut tercatat di audit_log. |
| D-020 | 2026-11-22 | Izin private key di Windows dibatasi dengan `icacls.exe` bawaan Windows (`/inheritance:r /grant:r <user>:F`); di OS lain `chmod 600`. Dipilih lewat `runtime.GOOS`, tanpa build tag. | PRD 8.2/14.2: private key hanya bisa dibaca user Windows saat ini. Tanpa dependency baru. |
| D-021 | 2026-11-22 | Variabel rahasia untuk perintah SSH (mis. `MYSQL_PWD`) dikirim lewat request `setenv` SSH. Bila server menolak, fallback `export VAR=...;` di awal perintah (hanya terlihat oleh user yang sama di CageFS). Akan dievaluasi ulang di Fase 4 dengan server Hostinger nyata. | PRD 8.7: password DB tidak boleh jadi argumen baris perintah. |
| D-022 | 2026-11-22 | Login SSH selalu mencoba key dulu. Password cadangan (Credential Manager, key `ssh-password:<akun>`) hanya dipakai bila login key gagal karena autentikasi. Password bisa dihapus dengan `migrator ssh remove-password <akun>`. | PRD 8.2 poin 5. |
| D-023 | 2026-11-22 | Aturan status Capability Audit: `SUPPORTED` hanya dari uji baca nyata (catatan diawali "Teruji"); operasi yang hanya ada di kontrak → `UNKNOWN` dengan fase pengujiannya; tidak ada endpoint tapi ada jalur manual → `MANUAL`; `QUOTA` selalu `UNKNOWN` karena `df` di shared hosting bukan kuota paket; SSH gagal → `MANUAL` (fallback `MANUAL_BACKUP`). Kode tambahan di luar tabel 8.3: `API_DB_LIST`, `API_PHP`, `API_SSH_KEY`, `API_EMAIL_INVENTORY/CREATE/DELETE/PASSWORD/BACKUP/RESTORE`. | AC-05 dan keputusan email D-008 s.d. D-010. Dibuktikan test `TestAuditNeverMarksUntestedAsSupported`. |
| D-024 | 2026-11-22 | Dalam audit, hanya 401/403 pada `hosting.websites.list` yang dianggap token dicabut (audit berhenti, token `DITOLAK`, exit 2). 401/403/404 pada endpoint lain (DNS, mail) dicatat `UNKNOWN` karena bisa berarti izin token terbatas atau zone ada di akun lain. | Menghindari salah tandai token sehat sebagai dicabut. |
| D-025 | 2026-11-22 | Kuota website per paket disimpan di `config.yaml` bagian `kuota_paket`: Single 1, Premium 100, Business 100 (paket lama Hostinger). | D-029 | 2026-11-22 | Aturan planner: domain yang sudah ada di akun tujuan → item `BLOCKED` (tidak ditimpa), rencana hanya ditolak bila semua item bentrok; website yang masih ada di batch aktif → `BLOCKED`; SSH sumber belum siap → peringatan + `MANUAL_BACKUP`; SSH tujuan belum siap → ditolak; sisa disk tujuan dari audit `QUOTA` (df) dibandingkan dengan ukuran × 1,3.
